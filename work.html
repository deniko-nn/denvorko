Проекты и подход к работе

Три задачи, которые чаще всего приходят от бизнеса: показать себя, продать онлайн и автоматизировать работу. Для каждой рассказываю, что было нужно, что сделал и на чём.

Многостраничный сайт

Корпоративный сайт студии интерьерного дизайна

Задача
Студия хотела показывать работы красиво, но старый сайт тяжело открывался на телефоне, а заявки терялись среди других кнопок.
Решение
Сделал каталог проектов с фильтром по типу помещения, крупные галереи с ленивой загрузкой изображений, форму заявки на замер, доступную из любого раздела, и структуру страниц под запросы вроде «дизайн интерьера» с привязкой к городу.
Что получилось
Лёгкие изображения, быстрая загрузка на мобильном интернете, заявка за два касания, микроразметка для расширенных сниппетов.
  • Next.js
  • TypeScript
  • Headless CMS
  • Schema.org

Интернет-магазин

Интернет-магазин авторской керамики

Задача
Мастерская продавала через соцсети и маркетплейсы, теряла комиссию и не могла показать товар так, как хотела.
Решение
Собрал магазин с карточками, где можно выбрать цвет и размер, корзиной, онлайн-оплатой и расчётом доставки. Каждая карточка получила микроразметку товара, а страницы категорий отвечают на поисковые запросы покупателей.
Что получилось
Собственный канал продаж без комиссий, понятный путь от карточки до оплаты, управление товарами без программиста.
  • React
  • Node.js
  • PostgreSQL
  • Платёжный шлюз

Веб-приложение

Личный кабинет сервиса онлайн-записи

Задача
Специалисты вели записи в таблицах и мессенджерах, путались в расписании и забывали напомнить клиентам.
Решение
Спроектировал кабинет с расписанием, карточками клиентов и автоматическими напоминаниями. Для администратора добавил панель с показателями, для клиента отдельный простой вход по ссылке.
Что получилось
Расписание в одном месте, меньше пропущенных записей, интерфейс, которым можно пользоваться без обучения.
  • React
  • TypeScript
  • REST API
  • Роли и права
