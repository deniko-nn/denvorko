# Анимации

Сюда кладутся все анимации сайта: каждая — отдельный компонент (`HeroWaves.tsx`, `Marquee.tsx` и т. д.).

**Как передать анимацию:** пришлите код (JS, GSAP, CSS, Canvas, Lottie, three.js) и скажите, на какой странице и в каком блоке она должна появиться. Я оберну её в компонент по шаблону `_Template.tsx`, подключу и проверю на телефоне и в обеих темах.

Внешние библиотеки (GSAP, Framer Motion и другие) ставятся через `npm i` по мере необходимости.
