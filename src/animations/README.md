# Анимации

Библиотеки и где они используются:

| Библиотека | Где на сайте |
|---|---|
| **GSAP** (`gsap.ts`, `HeroSequence.ts`) | Сцена загрузки главной (абзац, кнопки, факты, панель и строки кода); прорисовка линий шагов при прокрутке (ScrollTrigger, `components/ui.tsx`) |
| **React Bits** (`reactbits/`) | `SplitText`: заголовок главной по словам. `Magnet`: главная кнопка в hero. `SpotlightCard`: подсветка за курсором в блоке призыва к действию |
| **Framer Motion** | Плавная смена страниц (`Layout.tsx`), «переезжающее» подчёркивание в меню (`Header.tsx`), приподнимание карточек проектов (`HoverLift.tsx`) |
| **React Spring** | Наклон панели кода за курсором (`CodePanel.tsx`) |
| **React Transition Group** | Появление пунктов мобильного меню (`Header.tsx`), сообщение после отправки формы (`Contact.tsx`) |

Компоненты React Bits скопированы из реестра reactbits.dev (так устроена эта библиотека). В `SplitText` внесена правка: скрытие до старта через CSS-класс, чтобы заголовок был виден в статическом HTML и без JS.

## Правила для новых анимаций
1. Работа с DOM и `window` только внутри `useEffect`/`useGSAP`: при сборке страницы код выполняется на сервере.
2. Всё запущенное останавливаем в функции очистки.
3. Уважаем `prefers-reduced-motion`: `prefersReducedMotion()` или `useReducedMotion()`.
4. Цвета только из CSS-переменных (`var(--accent)`), чтобы работали обе темы.
5. Элементы, которые скрыты до старта анимации, получают класс `gsap-hide` (в CSS есть запасной показ через 3 секунды, если скрипт не загрузился).

## Как передать новую анимацию
Пришлите код и скажите, на какой странице и в каком блоке она нужна. Шаблон обёртки: `_Template.tsx`.
